== MODELO DE VENDA (2 opções por plugin) ==
Agora cada plugin pode ser cadastrado de 2 formas no admin:
1) "PRONTO (.amxx fixo)" - admin sobe um .amxx final.
   Cliente paga e recebe EXATAMENTE esse .amxx, SEM tag, SEM compilao.
2) "COM TAG (.sma)" - admin sobe o .sma.
   Sistema troca tag tipo [TRS] pela do cliente e compila na hora.

Admin pode enviar .amxx e/ou .sma no mesmo cadastro.
- Coluna "Entrega" no admin mostra "Pronto (.amxx)" ou "Com tag (.sma)".
- Pgina do plugin pronto NAO pede tag (badge "entregue pronto").
- delivery.js: se plugin tem amxxFile -> entrega direto (saved=pronto).
  Se tem so .sma -> fluxo normal de tag/compilacao.
- TESTADO: compra de plugin pronto entregou .amxx (1341 bytes), download 200,
  customTag vazio, saved=pronto. Plugin com tag segue funcionando.

## Fluxo de venda (com tag / .sma)
1. Cliente escolhe plugin, informa e-mail + TAG (ex: FURIA)
2. Sistema procura tags tipo [TRS] no .sma e troca pela tag do cliente
3. Pagamento via Mercado Pago (webhook em /api/webhook/mp)
4. Após aprovado -> compila .amxx AUTOMATICAMENTE (compilador AMXX 1.10)
5. Cliente baixa o .amxx; admin baixa o .sma pra conferir a tag

## Pagina de compilador online (tipo amx.worldcs.ro)
- URL: /compilador (link "Compilador" no menu)
- Envia .sma (+ .inc customizados se precisar) e recebe o .amxx compilado
- Funciona e testado (gerou .amxx valido)
